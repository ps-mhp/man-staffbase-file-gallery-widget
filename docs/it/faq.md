# Domande frequenti

**Domanda:** Il widget mostra il messaggio “Non hai accesso a questi file.”

Risposta: L’utente che ha effettuato l’accesso non è autorizzato a visualizzare la raccolta. Verifica i
diritti di accesso della raccolta nel File Manager.

**Domanda:** Il widget mostra il messaggio «Nessun file trovato».

Risposta: La raccolta (o, nel caso di **Tutti i file**, ogni raccolta visibile) non contiene file. Inserire i file in una raccolta nel Gestore file. Il widget non mostra i file che non appartengono a una raccolta.

**Domanda:** Il widget mostra il messaggio «Impossibile caricare i file: …»

Risposta: La richiesta non è andata a buon fine, ad esempio perché la raccolta è stata eliminata
o perché la connessione si è interrotta. Ricaricare la pagina; se il messaggio persiste, nella
finestra **Seleziona file**.

**Domanda:** Il widget mostra «Nessun file corrisponde al filtro.»

Risposta: Nessun file corrisponde a **Filtra per**, **Condizione** e **Valore**. Controllare i filtri o svuotare il campo **Valore**.

**Domanda:** Il widget mostra «Il filtro non è un’espressione regolare valida: …»

Risposta: L’espressione contiene un errore di sintassi, ad esempio una parentesi non chiusa. Correggere nella finestra o svuotare il campo **Valore** — in quel campo non è più possibile confermare un’espressione non valida.

**Domanda:** Una raccolta non è presente nell’elenco a sinistra.

Risposta: L’elenco mostra le raccolte a cui il proprio account ha accesso. Sotto il
modulo **Inserisci manualmente l’ID della raccolta**, apri il menu a tendina e inserisci l’ID o l’
indirizzo della raccolta.

**Domanda:** Nel Content Designer, per una galleria meno recente, la finestra mostra un ordinamento diverso rispetto alla pagina.

Risposta: Le versioni precedenti salvavano ogni impostazione in un proprio
campo; nel Content Designer i relativi campi di selezione non vengono letti. La
finestra mostra quindi l’impostazione predefinita, mentre nella pagina continua a valere il vecchio valore
. Non appena l’impostazione viene selezionata e confermata nella finestra, essa
diventa effettiva.
