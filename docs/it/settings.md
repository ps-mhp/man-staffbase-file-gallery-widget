# Ambientazioni

| Ambientazione | Descrizione |
| --- | --- |
| Collezione | La collezione dal file manager i cui file sono visualizzati. Campo richiesto. |
| Visualizzazione | **Riquadro**: Immagine di anteprima in alto, dettagli qui sotto (predefinito). **Lista**: Immagine di anteprima a sinistra, dettagli a destra. |
| Filter (espressione regolare) | Mostra solo file il cui nome file corrisponde all'espressione, distinzione per le maiuscole e minuscole (MIC). Esempi: solo PDF '\.pdf$', nomi '^2026' a partire da 2026, 'Report\| Log' uno dei due. Blank = tutti i file. |
| Mostra al massimo | Quanti file appaiono al massimo (dopo il filtro). '0' (predefinito) mostra tutto. |
