# Ambientazioni

| Ambientazione | Descrizione |
| --- | --- |
| Collezione (opzionale) | La collezione dal file manager i cui file sono visualizzati. Vuoto = i file **di tutte le collezioni** che i lettori possono vedere. I file che non fanno parte di una collezione non appariranno. |
| Ordine | Più recente per primo (predefinito), Più vecchio per primo, Nome A-Z, Nome Z-A, Primo più grande, Primo più piccolo. |
| Filtro: Campo | Su cosa funziona il filtro: **Nome file**, **Estensione file** (ad esempio 'pdf') o **Caricato da**. |
| Filtro: Condizione | **Contiene**, **Non contiene**, **Inizia con**, **Finisce con**, **Uguale** o **Corrisponde all'espressione regolare**. Insensibile alla maiuscoloscola. |
| Filtro: Valore | Il valore della condizione. Vuoto = nessun filtro. |
| Visualizzazione | **Riquadro**: Immagine di anteprima in alto, dettagli qui sotto (predefinito). **Lista**: Immagine di anteprima a sinistra, dettagli a destra. |
| Mostra al massimo | Il numero massimo di file che appaiono. '0' (predefinito) li mostra tutti. |

I passaggi si seguono in quest'ordine: prima **filtro**, poi **ordine**, 
poi **Mostra al massimo**. Quindi "Prima di nuovo" con 5 mostra i cinque
Ultimi file che corrispondono al filtro. 

Esempi di espressioni regolari nel nome del file: '^2026-\d\d_PIM_' (inizia
con il mese 2026, '_PIM_') oppure 'Segnalazione| Protocollo' (uno dei due).
