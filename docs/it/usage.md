# Passo dopo passo

## Preparare il caso di base

1. Creare una collezione in studio sotto **File** (o crearne una già esistente
   Usa) e ci metti dentro i file desiderati. 
2. Aggiungi il widget **File Gallery** alla pagina. 
3. Opzionalmente, seleziona una collezione nel campo **Collection (opzionale)**. Senza selezione, il widget mostrerà i file di tutte le collezioni. 
4. Opzionalmente, imposta un filtro: **Filter: Field**, **Filter: Condition** e **Filter: Value** (ad esempio Nome file · Contiene · 'PIM'). 
5. Sotto **Ordine**, specifica quale viene per primo e opzionalmente inserisci un numero sotto **Mostra al massimo**. 
6. Salva e anteprima. 

## Mostra gli ultimi file

1. **Ordine**: Seleziona "Nuovo per primo". 
2. **Mostra al massimo**: Inserisci la quantità, ad esempio 5. 
3. Opzionalmente, seleziona **Collection** e imposta un filtro per restringere la selezione. 

## Cambia dopo

1. Aggiungi o rimuovi file: direttamente nella collezione nel
   File Manager — la galleria mostra il nuovo stato la volta successiva che viene caricato. 
2. Mostra altra collezione: apri le impostazioni del widget e seleziona nel
   **Collezione (opzionale)** selezionane un'altra oppure cancella la selezione. 

## Quando qualcosa non funziona

1. Leggi il messaggio nel widget e cercalo nelle FAQ. 
2. Se la collezione manca dalla lista, "Inserisci un altro ID collezione..." 
   e inserire l'ID a 24 cifre della raccolta.
