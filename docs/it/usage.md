# Passo dopo passo

## Configurazione di base

1. In Studio, nella sezione **File**, creare una raccolta (o utilizzarne una già esistente
  ) e inserirvi i file desiderati.
2. Inserire nella pagina il widget **Galleria file**. Si aprirà la finestra
   **Seleziona file**.
3. A sinistra, sotto **Origine**, clicca sulla raccolta. Se non si seleziona nulla, viene applicata l’opzione
   **Tutti i file**: i file di tutte le raccolte.
4. Facoltativamente, sotto **Filtro e ordine**, imposta un filtro:
   **Filtra per**, **Condizione** e **Valore** (ad es. Nome file · contiene ·
   `PIM`).
5. In **Ordinamento**, specificare l’ordine di visualizzazione e, facoltativamente, in
   **Visualizzazione**, sotto **Al massimo**, inserire un numero.
6. In alto, selezionare **Desktop**, **Tablet** o **Mobile** e verificare il risultato
   nell’anteprima.
7. **Applica** e salva la finestra di dialogo delle impostazioni.

## Mostra i file più recenti

1. **Ordinamento**: seleziona «Più recenti per primi».
2. **Massimo**: inserisci un numero, ad es. 5.
3. Facoltativo: selezionare una raccolta a sinistra e impostare un filtro per
   restringere la selezione.

## Modificare in un secondo momento

1. Aggiungere o rimuovere file: direttamente nella raccolta nel
   Gestore file — la galleria mostrerà lo stato aggiornato al prossimo caricamento.
2. Visualizzare un’altra raccolta: aprire le impostazioni del widget, nella finestra
   **Seleziona file** a sinistra cliccare su un’altra raccolta o su **Tutti i file**
   e confermare.

## Se qualcosa non funziona

1. Leggere il messaggio nel widget e consultare le FAQ.
2. Se una raccolta non è presente nell’elenco a sinistra, sotto il modulo
   **Inserisci manualmente l’ID della raccolta**, apri il menu a tendina e inserisci l’ID di 24 cifre o
   l’indirizzo della raccolta.
3. Se l’elenco non si carica, compare il messaggio **Riprova**.
