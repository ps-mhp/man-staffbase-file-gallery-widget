# Ustawienia

| Miejsce akcji | Opis |
| --- | --- |
| Kolekcja | Kolekcja z menedżera plików, którego pliki są wyświetlane. Pole wymagane. |
| Wyświetlacz | **Ramka**: Obraz podglądowy na górze, szczegóły poniżej (domyślnie). **Lista**: Obraz podglądowy po lewej, szczegóły po prawej. |
| Filtr (wyrażenie regularne) | Wyświetla tylko pliki, których nazwa pliku odpowiada wyrażeniu, rozróżniające wielka litera. Przykłady: tylko PDF-y '\.pdf$', nazwy '^2026' zaczynające się od 2026, 'Raport\| Loguj' jeden z tych dwóch. Puste = wszystkie pliki. |
| Pokaż maksymalnie | Ile plików pojawia się najwyżej (po filtrze). '0' (domyślnie) pokazuje wszystko. |
