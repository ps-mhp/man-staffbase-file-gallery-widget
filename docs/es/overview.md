# Galería de archivos

La galería de archivos muestra todos los archivos de una colección desde el gestor de archivos
(Studio → Archivos) en una página. Si añades archivos a la colección
o si se elimina de ella, esto también cambia la galería — la página en sí debe ser
no se procesan para esto. 

## Lo que ven los lectores

Una cuadrícula de mosaicos. Cada mosaico muestra una imagen de vista previa (para archivos sin
Vista previa del tipo de archivo, como PDF), incluyendo el nombre, tipo y tamaño del archivo. En
Haz clic para abrir el archivo en una pestaña nueva. 

## Lo que ves en el editor CMS

La misma cuadrícula que en la página publicada.
