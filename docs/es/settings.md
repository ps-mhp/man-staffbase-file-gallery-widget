# Escenarios

| Ambientación | Descripción |
| --- | --- |
| Colección | La colección del gestor de archivos cuyos archivos se muestran. Campo requerido. |
| Pantalla | **Recuadro**: Imagen de vista previa en la parte superior, detalles abajo (por defecto). **Lista**: Imagen de vista previa a la izquierda, detalles a la derecha. |
| Filter (Expresión regular) | Solo muestra archivos cuyo nombre coincide con la expresión, sensible a mayúsculas. Ejemplos: solo PDFs '\.pdf$', nombres '^2026' que empiezan por 2026, 'Report\| Log' uno de los dos. Blank = todos los archivos. |
| Mostrar como máximo | Cuántos archivos aparecen como máximo (después del filtro). '0' (por defecto) muestra todo. |
