# Décors

| Cadre | Description |
| --- | --- |
| Collection | La collection provenant du gestionnaire de fichiers dont les fichiers sont affichés. Champ requis. |
| Affichage | **Boîte** : Image d’aperçu en haut, détails ci-dessous (par défaut). **Liste** : Image d’aperçu à gauche, détails à droite. |
| Filter (expression régulière) | Affiche uniquement les fichiers dont le nom de fichier correspond à l’expression, à la majuscule. Exemples : PDF « \.pdf$ » uniquement, noms « ^2026 » commençant par 2026, « Report\| Log » l’un des deux. Blank = tous les fichiers. |
| Afficher au maximum | Combien de fichiers apparaissent au maximum (après le filtre). « 0 » (par défaut) affiche tout. |
