# FAQ

**Question :** Le widget indique « Vous n’avez pas accès à ces fichiers. » 

Réponse : La personne connectée n’est pas autorisée à lire la collection. Dans le
Gestionnaire de fichiers, vérifiez les droits d’accès de la collection. 

**Question :** Le widget affiche « Aucun fichier trouvé. » 

Réponse : La collection (ou, sans sélection, toute collection visible) ne contient aucun fichier. Placez les fichiers dans une collection dans le gestionnaire de fichiers. Les fichiers sans collection ne sont pas affichés dans le widget. 

**Question :** Le widget affiche « Échec du chargement des fichiers : ... » 

Réponse : La requête a échoué, par exemple parce que la collection a été supprimée
ou la connexion a été perdue. recharger la page ; le message que
Resélectionnez Collection dans les paramètres. 

**Question :** Le widget affiche « Aucun fichier ne correspond au filtre. » 

Réponse : Aucun fichier ne correspond à **Filter : Field**, **Condition** et **Value**. Vérifiez le filtre ou effacez la valeur. 

**Question :** Le widget indique « Le filtre n’est pas une expression régulière valide : ... » 

Réponse : L’expression contient une erreur de syntaxe, telle qu’une parenthèse non fermée. Corrigez ou effacez le champ.
