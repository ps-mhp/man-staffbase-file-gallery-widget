# FAQ

**Question :** Le widget affiche « Vous n'avez pas accès à ces fichiers. »

Réponse : L'utilisateur connecté n'est pas autorisé à consulter la collection. Vérifiez les
droits d'accès de la collection dans le gestionnaire de fichiers.

**Question :** Le widget affiche « Aucun fichier trouvé. »

Réponse : La collection (ou, dans le cas de **Tous les fichiers**, toute collection visible) ne contient aucun fichier. Placez des fichiers dans une collection via le gestionnaire de fichiers. Le widget n’affiche pas les fichiers qui ne sont pas associés à une collection.

**Question :** Le widget affiche « Impossible de charger les fichiers : … »

Réponse : La requête a échoué, par exemple parce que la collection a été supprimée
ou que la connexion a été interrompue. Actualisez la page ; si le message persiste,
fenêtre **Sélectionner des fichiers**, choisissez une nouvelle source.

**Question :** Le widget affiche « Aucun fichier ne correspond au filtre. »

Réponse : Aucun fichier ne correspond aux paramètres **Filtrer par**, **Condition** et **Valeur**. Vérifiez les filtres ou effacez la valeur.

**Question :** Le widget affiche « Le filtre n’est pas une expression régulière valide : … »

Réponse : L’expression contient une erreur de syntaxe, par exemple une parenthèse non fermée. Corrigez-la dans la fenêtre ou videz le champ **Valeur** — une expression non valide ne peut plus y être validée.

**Question :** Une collection manque dans la liste de gauche.

Réponse : La liste affiche les collections auxquelles votre compte a accès. Sous le
formulaire **Saisir manuellement l’ID de la collection**, développez le menu et insérez l’ID ou l’
adresse de la collection.

**Question :** Dans le Content Designer, la fenêtre affiche un tri différent de celui de la page pour une ancienne galerie.

Réponse : Les anciennes versions enregistraient chaque paramètre dans un
champ distinct ; dans le Content Designer, leurs champs de sélection ne peuvent pas être lus. La
fenêtre affiche alors le paramètre par défaut, tandis que l’ancienne valeur
reste valable sur la page. Dès que le paramètre est sélectionné et appliqué dans la fenêtre,
il s’applique.
