# Configurações

| Cenário | Descrição |
| --- | --- |
| Coleção | A coleção do gerenciador de arquivos cujos arquivos são exibidos. Campo obrigatório. |
| Exibição | **Caixa**: Imagem de pré-visualização no topo, detalhes abaixo (padrão). **Lista**: Imagem de pré-visualização à esquerda, detalhes à direita. |
| Filter (Expressão Regular) | Mostra apenas arquivos cujo nome de arquivo corresponde à expressão, com sensibilidade a maiúsculas e minúsculas. Exemplos: PDFs '\.pdf$' apenas, nomes '^2026' começando com 2026, 'Report\| Log' um dos dois. Blank = todos os arquivos. |
| Mostrar no máximo | Quantos arquivos aparecem no máximo (após o filtro). '0' (padrão) mostra todos. |
