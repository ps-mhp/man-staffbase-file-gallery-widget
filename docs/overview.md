# Dateigalerie

Die Dateigalerie zeigt Dateien aus dem Datei-Manager (Studio → Dateien) auf
einer Seite an: die einer Sammlung oder, ohne Wahl, die aller Sammlungen.
Dateien lassen sich filtern, sortieren und auf eine Anzahl begrenzen, z. B.
als „die 5 neuesten PDFs“. Wer Dateien in die Sammlung legt
oder aus ihr entfernt, ändert damit auch die Galerie — die Seite selbst muss
dafür nicht bearbeitet werden.

## Was Leser:innen sehen

Ein Raster aus Kacheln oder eine Liste. Jede Datei zeigt ein Vorschaubild
(bei Dateien ohne Vorschau den Dateityp, z. B. „PDF“), dazu Dateiname, Typ
und Größe. Ein Klick öffnet die Datei in einem neuen Tab.

## Was Sie im CMS-Editor sehen

Dasselbe wie auf der veröffentlichten Seite. Eingestellt wird im Fenster
**Dateien auswählen**: links die Quelle, in der Mitte Filter, Sortierung und
Darstellung, auf Wunsch eine Vorschau für Desktop, Tablet und Mobil.
