# Dateigalerie

Die Dateigalerie zeigt alle Dateien einer Collection aus dem Datei-Manager
(Studio → Dateien) auf einer Seite an. Wer Dateien in die Collection legt
oder aus ihr entfernt, ändert damit auch die Galerie — die Seite selbst muss
dafür nicht bearbeitet werden.

## Was Leser:innen sehen

Ein Raster aus Kacheln. Jede Kachel zeigt ein Vorschaubild (bei Dateien ohne
Vorschau den Dateityp, z. B. „PDF“), darunter Dateiname, Typ und Größe. Ein
Klick öffnet die Datei in einem neuen Tab.

## Was Sie im CMS-Editor sehen

Dasselbe Raster wie auf der veröffentlichten Seite.
