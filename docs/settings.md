# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Collection | Die Collection aus dem Datei-Manager, deren Dateien angezeigt werden. Pflichtfeld. |
| Darstellung | **Box**: Vorschaubild oben, Details darunter (voreingestellt). **Liste**: Vorschaubild links, Details rechts. |
| Filter (regulärer Ausdruck) | Zeigt nur Dateien, deren Dateiname zum Ausdruck passt, ohne Beachtung der Groß-/Kleinschreibung. Beispiele: `\.pdf$` nur PDFs, `^2026` Namen, die mit 2026 beginnen, `Bericht\|Protokoll` eines von beiden. Leer = alle Dateien. |
| Höchstens anzeigen | Wie viele Dateien höchstens erscheinen (nach dem Filter). `0` (voreingestellt) zeigt alle. |
