# Schritt für Schritt

## Grundfall einrichten

1. Im Studio unter **Dateien** eine Collection anlegen (oder eine vorhandene
   nutzen) und die gewünschten Dateien hineinlegen.
2. Auf der Seite das Widget **Dateigalerie** einfügen.
3. Im Feld **Collection** die Collection aus der Liste wählen.
4. Optional unter **Höchstens anzeigen** eine Anzahl eintragen.
5. Speichern und in der Vorschau prüfen.

## Nachträglich ändern

1. Dateien hinzufügen oder entfernen: direkt in der Collection im
   Datei-Manager — die Galerie zeigt den neuen Stand beim nächsten Laden.
2. Andere Collection zeigen: Widget-Einstellungen öffnen und im Feld
   **Collection** eine andere wählen.

## Wenn etwas nicht funktioniert

1. Meldung im Widget lesen und im FAQ nachschlagen.
2. Fehlt die Collection in der Liste, „Andere Collection-ID eingeben …“
   wählen und die 24-stellige ID der Collection eintragen.
