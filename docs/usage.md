# Schritt für Schritt

## Grundfall einrichten

1. Im Studio unter **Dateien** eine Sammlung anlegen (oder eine vorhandene
   nutzen) und die gewünschten Dateien hineinlegen.
2. Auf der Seite das Widget **Dateigalerie** einfügen. Das Fenster
   **Dateien auswählen** öffnet sich.
3. Links unter **Quelle** die Sammlung anklicken. Ohne Wahl gilt
   **Alle Dateien**: die Dateien aller Sammlungen.
4. Optional unter **Filter & Reihenfolge** einen Filter einrichten:
   **Filtern nach**, **Bedingung** und **Wert** (z. B. Dateiname · enthält ·
   `PIM`).
5. Unter **Sortierung** festlegen, was zuerst kommt, und optional unter
   **Darstellung** bei **Höchstens** eine Anzahl eintragen.
6. Oben auf **Desktop**, **Tablet** oder **Mobil** schalten und das Ergebnis
   in der Vorschau prüfen.
7. **Übernehmen** und den Einstellungsdialog speichern.

## Die neuesten Dateien zeigen

1. **Sortierung**: „Neueste zuerst“ wählen.
2. **Höchstens**: Anzahl eintragen, z. B. 5.
3. Optional links eine Sammlung wählen und einen Filter setzen, um die
   Auswahl einzuengen.

## Nachträglich ändern

1. Dateien hinzufügen oder entfernen: direkt in der Sammlung im
   Datei-Manager — die Galerie zeigt den neuen Stand beim nächsten Laden.
2. Andere Sammlung zeigen: Widget-Einstellungen öffnen, im Fenster
   **Dateien auswählen** links eine andere Sammlung oder **Alle Dateien**
   anklicken und übernehmen.

## Wenn etwas nicht funktioniert

1. Meldung im Widget lesen und im FAQ nachschlagen.
2. Fehlt eine Sammlung in der Liste links, unter dem Formular
   **Sammlungs-ID von Hand eintragen** aufklappen und die 24-stellige ID oder
   die Adresse der Sammlung einfügen.
3. Lädt die Liste nicht, steht dort **Erneut versuchen**.
