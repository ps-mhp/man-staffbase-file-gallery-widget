# Schritt für Schritt

## Grundfall einrichten

1. Im Studio unter **Dateien** eine Collection anlegen (oder eine vorhandene
   nutzen) und die gewünschten Dateien hineinlegen.
2. Auf der Seite das Widget **Dateigalerie** einfügen.
3. Optional im Feld **Collection (optional)** eine Collection wählen. Ohne Auswahl zeigt das Widget die Dateien aller Collections.
4. Optional einen Filter einrichten: **Filter: Feld**, **Filter: Bedingung** und **Filter: Wert** (z. B. Dateiname · Enthält · `PIM`).
5. Unter **Reihenfolge** festlegen, was zuerst kommt, und optional unter **Höchstens anzeigen** eine Anzahl eintragen.
6. Speichern und in der Vorschau prüfen.

## Die neuesten Dateien zeigen

1. **Reihenfolge**: „Neueste zuerst“ wählen.
2. **Höchstens anzeigen**: Anzahl eintragen, z. B. 5.
3. Optional **Collection** wählen und einen Filter setzen, um die Auswahl einzuengen.

## Nachträglich ändern

1. Dateien hinzufügen oder entfernen: direkt in der Collection im
   Datei-Manager — die Galerie zeigt den neuen Stand beim nächsten Laden.
2. Andere Collection zeigen: Widget-Einstellungen öffnen und im Feld
   **Collection (optional)** eine andere wählen oder die Auswahl leeren.

## Wenn etwas nicht funktioniert

1. Meldung im Widget lesen und im FAQ nachschlagen.
2. Fehlt die Collection in der Liste, „Andere Collection-ID eingeben …“
   wählen und die 24-stellige ID der Collection eintragen.
