# FAQ

**Question:** The widget displays “You do not have access to these files.”

Answer: The logged-in user does not have read access to the collection. In
File Manager, check the collection’s access permissions.

**Question:** The widget displays “No files found.”

Answer: The collection (or, in the case of **All Files**, any visible collection) contains no files. Place files into a collection in the File Manager. The widget does not display files that are not part of a collection.

**Question:** The widget displays “Files could not be loaded: …”

Answer: The request failed, e.g., because the collection was deleted
or the connection was lost. Reload the page; if the message persists,
**Select Files** window.

**Question:** The widget displays “No files match the filter.”

Answer: No files match the **Filter By**, **Condition**, and **Value**. Check the filter or clear the value.

**Question:** The widget displays “The filter is not a valid regular expression: …”

Answer: The expression contains a syntax error, such as an unclosed parenthesis. Correct it in the window or clear the **Value** field—an invalid expression cannot be saved there.

**Question:** A collection is missing from the list on the left.

Answer: The list shows the collections that your account is authorized to view. Under the
**Enter Collection ID Manually** form, expand it and enter the ID or the
address of the collection.

**Question:** In the Content Designer, the window displays a different sort order for an older gallery than the page does.

Answer: Older versions stored each setting in its own
field; in the Content Designer, those selection fields cannot be read. The
window then displays the default setting, while the old value
still applies on the page. As soon as the setting is selected and applied in the window,
it takes effect.
