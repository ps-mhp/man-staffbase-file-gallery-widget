# Settings

| Setting | Description |
| --- | --- |
| Collection | The collection from the file manager whose files are displayed. Required field. |
| Display | **Box**: Preview image at the top, details below (default). **List**: Preview image on the left, details on the right. |
| Filter (Regular Expression) | Shows only files whose filename matches the expression, case sensitive. Examples: '\.pdf$' PDFs only, '^2026' names starting with 2026, 'Report\| Log' one of the two. Blank = all files. |
| Show at most | How many files appear at most (after the filter). '0' (default) shows all. |
