# Step by Step

## Setting Up a Basic Case

1. In Studio, under **Files**, create a collection (or use an existing
   one) and add the desired files to it.
2. Insert the **File Gallery** widget onto the page. The
   **Select Files** window opens.
3. On the left, under **Source**, click the collection. If no selection is made,
   **All Files** is selected by default: the files from all collections.
4. Optionally, set up a filter under **Filter & Order**:
   **Filter by**, **Condition**, and **Value** (e.g., filename · contains ·
   `PIM`).
5. Under **Sorting**, specify the order, and optionally enter a number under
   **Display**, enter a number under **Maximum**.
6. At the top, switch to **Desktop**, **Tablet**, or **Mobile** and check the result
   in the preview.
7. Click **Apply** to save the settings dialog.

## Show the latest files

1. **Sorting**: Select “Newest first.”
2. **Max**: Enter a number, e.g., 5.
3. Optionally, select a collection on the left and apply a filter to
   narrow down the selection.

## Making Changes Later

1. Add or remove files: directly in the collection in the
   File Manager—the gallery will display the updated view the next time it loads.
2. Show a different collection: Open the widget settings, in the
   **Select Files** window on the left, click a different collection or **All Files**
   and apply the changes.

## If something isn’t working

1. Read the message in the widget and check the FAQ.
2. If a collection is missing from the list on the left, expand the
   **Enter Collection ID Manually** field below the form and enter the 24-digit ID or
   the collection’s URL.
3. If the list doesn’t load, you’ll see **Try Again** there.
