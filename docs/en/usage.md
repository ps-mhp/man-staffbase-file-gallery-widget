# Step by step

## Set up the basic case

1. Create a collection in the studio under **Files** (or create an existing one
   use) and put the desired files in it. 
2. Add the **File Gallery** widget to the page. 
3. Optionally, select a collection in the **Collection (optional)** field. Without selection, the widget will show the files of all collections. 
4. Optionally, set up a filter: **Filter: Field**, **Filter: Condition** and **Filter: Value** (e.g. Filename · Contains · 'PIM'). 
5. Under **Order**, specify which comes first, and optionally enter a number under **Show at most**. 
6. Save and preview. 

## Show the latest files

1. **Order**: Select "Newest first". 
2. **Show at most**: Enter the quantity, e.g. 5. 
3. Optionally, select **Collection** and set a filter to narrow the selection. 

## Change afterwards

1. Add or remove files: directly in the collection in the
   File Manager — the gallery shows the new state the next time it is loaded. 
2. Show other collection: Open widget settings and select in the
   **Collection (optional)** select another one or clear the selection. 

## When something doesn't work

1. Read the message in the widget and look it up in the FAQ. 
2. If the collection is missing from the list, "Enter another collection ID..." 
   and enter the 24-digit ID of the collection.
