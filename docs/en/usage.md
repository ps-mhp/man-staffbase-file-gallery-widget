# Step by step

## Set up the basic case

1. Create a collection in the studio under **Files** (or create an existing one
   use) and put the desired files in it. 
2. Add the **File Gallery** widget to the page. 
3. In the **Collection** field, select the collection from the list. 
4. Optionally, enter a number under **Show at most**. 
5. Save and preview. 

## Change afterwards

1. Add or remove files: directly in the collection in the
   File Manager — the gallery shows the new state the next time it is loaded. 
2. Show other collection: Open widget settings and select in the
   **Collection** choose another one. 

## When something doesn't work

1. Read the message in the widget and look it up in the FAQ. 
2. If the collection is missing from the list, "Enter another collection ID..." 
   and enter the 24-digit ID of the collection.
