# Bestandsgalerij

De bestandsgalerij toont alle bestanden van een collectie vanuit de bestandsbeheerder
(Studio → Bestanden) op een pagina. Als je bestanden aan de collectie toevoegt
of verwijderd, verandert dit ook de galerij — de pagina zelf moet
worden hiervoor niet verwerkt. 

## Wat lezers zien

Een raster van tegels. Elke tegel toont een voorbeeldafbeelding (voor bestanden zonder
Bekijk het bestandstype, zoals PDF), inclusief bestandsnaam, type en grootte. Op
Klik opent het bestand in een nieuw tabblad. 

## Wat je ziet in de CMS-editor

Zelfde raster als op de gepubliceerde pagina.
