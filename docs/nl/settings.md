# Instellingen

| Setting | Beschrijving |
| --- | --- |
| Collectie | De collectie van de bestandsbeheerder waarvan de bestanden worden weergegeven. Vereist veld. |
| Weergeven | **Vakken**: Afbeelding bovenaan, details hieronder (standaard). **Lijst**: Afbeelding links bekijken, details rechts. |
| Filter (Reguliere Expressie) | Toont alleen bestanden waarvan de bestandsnaam overeenkomt met de expressie, hoofdlettergevoelig. Voorbeelden: '\.pdf$' alleen PDF's, '^2026' namen beginnend met 2026, 'Report\| Log' één van de twee. Blanco = alle bestanden. |
| Toon maximaal | Hoeveel bestanden er hooguit verschijnen (na het filter). '0' (standaard) toont alle. |
