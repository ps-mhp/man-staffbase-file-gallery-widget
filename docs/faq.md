# FAQ

**Frage:** Das Widget zeigt „Keine Collection gewählt. Bitte in den Widget-Einstellungen eine Collection auswählen.“

Antwort: Im Feld **Collection** ist noch nichts gewählt. Widget-Einstellungen
öffnen und eine Collection auswählen.

**Frage:** Das Widget zeigt „Sie haben keinen Zugriff auf diese Dateien.“

Antwort: Die angemeldete Person darf die Collection nicht lesen. Im
Datei-Manager die Zugriffsrechte der Collection prüfen.

**Frage:** Das Widget zeigt „Diese Collection enthält keine Dateien.“

Antwort: Die Collection ist leer. Dateien im Datei-Manager hineinlegen.

**Frage:** Das Widget zeigt „Dateien konnten nicht geladen werden: …“

Antwort: Die Anfrage ist fehlgeschlagen, z. B. weil die Collection gelöscht
wurde oder die Verbindung abbrach. Seite neu laden; bleibt die Meldung, die
Collection in den Einstellungen neu auswählen.
