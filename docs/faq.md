# FAQ

**Frage:** Das Widget zeigt „Sie haben keinen Zugriff auf diese Dateien.“

Antwort: Die angemeldete Person darf die Sammlung nicht lesen. Im
Datei-Manager die Zugriffsrechte der Sammlung prüfen.

**Frage:** Das Widget zeigt „Keine Dateien gefunden.“

Antwort: Die Sammlung (oder, bei **Alle Dateien**, jede sichtbare Sammlung) enthält keine Dateien. Dateien im Datei-Manager in eine Sammlung legen. Dateien ohne Sammlung zeigt das Widget nicht.

**Frage:** Das Widget zeigt „Dateien konnten nicht geladen werden: …“

Antwort: Die Anfrage ist fehlgeschlagen, z. B. weil die Sammlung gelöscht
wurde oder die Verbindung abbrach. Seite neu laden; bleibt die Meldung, im
Fenster **Dateien auswählen** die Quelle neu wählen.

**Frage:** Das Widget zeigt „Keine Datei passt zum Filter.“

Antwort: Keine Datei passt zu **Filtern nach**, **Bedingung** und **Wert**. Filter prüfen oder den Wert leeren.

**Frage:** Das Widget zeigt „Der Filter ist kein gültiger regulärer Ausdruck: …“

Antwort: Der Ausdruck enthält einen Syntaxfehler, z. B. eine nicht geschlossene Klammer. Im Fenster korrigieren oder das Feld **Wert** leeren — übernehmen lässt sich ein ungültiger Ausdruck dort nicht mehr.

**Frage:** Eine Sammlung fehlt in der Liste links.

Antwort: Die Liste zeigt die Sammlungen, die Ihr Konto sehen darf. Unter dem
Formular **Sammlungs-ID von Hand eintragen** aufklappen und die ID oder die
Adresse der Sammlung einfügen.

**Frage:** Im Content Designer zeigt das Fenster bei einer älteren Galerie eine andere Sortierung als die Seite.

Antwort: Ältere Fassungen speicherten jede Einstellung in einem eigenen
Feld; im Content Designer lassen sich deren Auswahlfelder nicht lesen. Das
Fenster zeigt dann die Voreinstellung, an der Seite gilt der alte Wert
weiter. Sobald die Einstellung im Fenster gewählt und übernommen ist, gilt
sie.
